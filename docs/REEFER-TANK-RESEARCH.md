# 범위 제외 기록

냉동·탱크는 OOG 핵심 완료 범위에서 제외한다. 아래는 과도하게 확장했던 당시 조사 기록이며 현재 기능 설명이 아니다.

# 냉동과 탱크 전용 검토 요구사항

확인일 2026-10-14. S01 자료 분석 단계다. 현재 전용 계산/판정 기능은 미구현이며 일반 기하 배치와 분리하여 개발해야 한다.

## 냉동 장비

[MSC 공식 냉동 운송 안내](https://www.msc.com/en/solutions/reefer-cargo?tab=video)는 온도·환기·습도 제어, PTI와 운송 중 모니터링, 공기 순환을 위한 최대 적재선을 설명한다. 적재 높이는 외형 높이나 일반 컨테이너 내측 높이와 같은 값으로 취급할 수 없다. T-floor 끝과 적재선, 공기 통로를 별도 제약으로 입력해야 한다.

[Maersk 냉동 컨테이너 설명](https://www.maersk.com/ko-kr/logistics-explained/transportation-and-freight/2025/03/06/reefer-containers)도 온도·습도·환기의 제어를 구분한다. 특정 품목의 온도나 환기 설정을 전체 냉동 화물 기본값으로 생성하지 않는다.

구현 입력은 실제 장비 모델/적재선/유효 바닥 구간, 화주의 운송 조건과 설정 근거, 화물 입고 온도, PTI 증빙, 전원/환적 계획, 모니터링 책임과 예외 처리다. 자동 점검은 자료 누락과 선언 조건 불일치부터 시작한다. 냉각능력이나 온도 이력 예측은 열부하·장비 성능·외기·시간 조건을 확보한 별도 모델이 필요하다. 항목이 채워졌다는 이유로 화물 품질이나 온도 유지 성능을 승인하지 않는다.

## 탱크 장비

[ITCO 액체 벌크 운송 기술 안내](https://www.international-tank-container.org/en/technical/technical-guidance-for-shipping-bulk-liquids)는 액체 밀도, 장비와 운송 구간의 중량 한계, 열팽창과 충전율, 배플 유무 및 탱크별 T-code 조건을 구분한다. 95%는 일부 운영 정책에서 제안하는 값이며 모든 물질·탱크·구간의 보편 규정으로 하드코딩하지 않는다. 원문은 IMDG 조항을 참조하지만 해당 일반 웹 안내만으로 현행 규정 전체를 대체하지 않는다.

[ITCO 안전 안내](https://www.international-tank-container.org/en/technical/safety)와 기술 안내의 20% 경계 표현도 같지 않다. 경계값은 적용 규정과 운영자 확인 자료를 확보하기 전 자동 통과시키지 않는다.

구현 입력은 탱크 식별/설계 형식·공칭 용량·자중/최대 총중량·적용 구간 한계, 물질 식별/SDS·해당 온도의 밀도·열팽창 자료·예상 온도 범위, 운영자가 확인한 충전율 제한과 적용 조건, 재질/라이닝·세척/직전 화물·검사 증빙이다. 액체 이동에 따른 자유수면/슬로싱 검토는 일반 고체 화물의 CoG·Coulomb 계산으로 대체하지 않는다. 위험물 분류와 현행 규정 적합성을 별도 확인해야 한다.

## 후속 구현과 검증 기준

출처/적용일/실제 장비·물질별 확인 근거가 있는 선언 규칙을 버전별로 보존한다. 미입력은 미확인, 출처 불일치는 검토 필요로 반환한다. 온도·밀도·체적의 단위를 명시하고 경계값·누락·서로 모순되는 조건을 코드로 검증한다. 일반 CLP가 냉동·탱크 운송 승인으로 변환되지 않도록 모델과 상태를 분리한다. 현재는 이 요구사항 분석과 출처 확인까지만 진행했으며 S01 검증 통과로 집계하지 않는다.
