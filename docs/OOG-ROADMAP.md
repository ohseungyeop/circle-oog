# Circle OOG 개발 로드맵

현재 기능 목록은 25개이며 완료 18·미완료 7(진행 3·미착수 4), 검증 통과 17·대기 8이다. 단계 B06의 기존 장비 간 Move/Lock·불변 개정·CLP Excel과 B02의 원치수·자동 매핑 제안·중량 기준, H01 이력 조회는 내부 구현/API 검증을 마쳤다. B05 공통 인증과 B07 Master·다중 Rule·OR-Tools는 남아 있다. 단계 전체 완료와 기능별 완료를 혼동하지 않는다.

## 개발 단계

| 단계 | 기능 | 완료 기준 |
|---|---|---|
| B01 | 신규 제품 기반, FMS 공통 재사용, 독립 DB | 빌드·DB 마이그레이션·초기 인증 |
| B02 | 프로젝트·화물·Excel 가져오기 | 실제 샘플 매핑·오류 전체 거부·원본 보존 |
| B03 | OOG·장비·규칙 | 경계값 검증·후보 사유·규칙 변경·이력 |
| B04 | 보수적 CLP·2D·출력 | 수량 보존·겹침/중량 제약·재조회·출력 |
| B05 | 공통 사용자·회사·JWT·RBAC | OOG DB에서 역할/회사 경계 검증 |
| B06 | 수동 Move/Lock·계획 개정·CLP Excel | 잠금 보존·잘못된 배치 거부·불변 이력 |
| B07 | OR-Tools·다중 Rule·장비 Master 편집 | 목적함수·제약·실제 선사 기준 검증 |
| B08 | 견적·포장 추정·라싱 Pre-plan | 비용 근거·예상/확정 구분·검토 흐름 |
| B09 | 3D·공학·외부 연동 | 별도 승인·공식 규격·실제 시험 |

제품 분석 문서의 전체 MVP는 B01–B07을 포함한다. 초기 코드가 있다고 전체 MVP 완료로 선언하지 않는다. 실제 업무 승인과 공학 검증은 개발 빌드와 별도로 관리한다.
