# Circle OOG 개발 로드맵

현재 OOG 핵심 기능 34개 중 완료 32·미완료 2(진행 2·미착수 0), 검증 통과 32·대기 2이다. 자동 탐지·자동 CLP/추천·포장 추정/사전견적·Multi-FR 후보 및 수동 선택을 구현했다. 제한된 공학 계산·내부 검토와 B07의 1열 OR-Tools 모델을 추가했다. 실제 선사 기준 검증, 확대 공학 모델, 추가 FMS 공통 설정은 별도 범위다. 단계 전체 완료와 기능별 내부 범위를 구분한다.

## 개발 단계

| 단계 | 기능 | 완료 기준 |
|---|---|---|
| B01 | 신규 제품 기반, FMS 공통 재사용, 독립 DB | 빌드·DB 마이그레이션·초기 인증 |
| B02 | 프로젝트·화물·Excel 가져오기 | 실제 샘플 매핑·오류 전체 거부·원본 보존 |
| B03 | OOG·장비·규칙 | 경계값 검증·후보 사유·규칙 변경·이력 |
| B04 | 보수적 CLP·2D·출력 | 수량 보존·겹침/중량 제약·재조회·출력 |
| B05 | 공통 사용자·회사·JWT·RBAC | OOG DB에서 역할/회사 경계 검증 |
| B06 | 수동 Move/Lock·계획 개정·CLP Excel | 잠금 보존·잘못된 배치 거부·불변 이력 |
| B07 | OR-Tools·다중 Rule·장비 Master 편집 | 모델 목적함수·제약·fallback 구분과 실제 선사 기준 검증 |
| B08 | 견적·포장 추정·라싱 Pre-plan | 비용 근거·예상/확정 구분·검토 흐름 |
| B09 | 3D·공학·외부 연동 | 별도 승인·공식 규격·실제 시험 |

제품 분석 문서의 전체 MVP는 B01–B07을 포함한다. 초기 코드가 있다고 전체 MVP 완료로 선언하지 않는다. 실제 업무 승인과 공학 검증은 개발 빌드와 별도로 관리한다.

## 이번 확장 범위와 다음 검토

Excel 고객별 템플릿은 회사·고객·정확한 헤더가 일치할 때 최신 버전을 추천하고 사용자가 적용한다. `.xls`와 `.xlsx`는 같은 매핑·검증 경로를 사용한다. 단위·중량 기준의 근거가 없으면 수동 확인을 요구하며 원본 자료의 의미까지 자동 확정하지 않는다. 저장된 사전 견적은 해당 버전의 입력·단가·대안별 금액과 누락 상태를 Excel/PDF로 전달한다.

B07의 AUTO는 OR-Tools CP-SAT로 적층 없는 1열 모델의 장비 대수를 최소화하며 HEURISTIC 수동 선택을 유지한다. 최적해 증명과 실행 가능한 해를 구분하고 규모·시간 한도 및 fallback 이유를 기록한다. 실제 선사 규칙·장비 제원 승인, 2D/적층·비용/Slot Loss 목적함수는 별도 작업이다. [모델 범위](OPTIMIZATION.md)를 기준으로 구현 상태와 실무 적합성을 나누어 검토한다.

B08/B09의 공학 확장은 CoG 입력과 확인 근거, 두 지지점의 정적 반력·평균 면압, 단일 방향 직접 라싱 미끄럼 필요조건, 독립 검토자 내부 결정까지다. 저장 질량 불일치·추정값·누락값·한도 초과·자기 승인을 차단한다. 전도·동적 반력·구조 강도·다점 분배·전체 운송 경로와 선사 승인은 [공학 계산 문서](ENGINEERING-CALCULATIONS.md)의 제외 범위로 남긴다. 내부 승인 이후에도 PRE_PLAN을 유지한다. 세부 기능 수치와 실제 검증 결과는 기능별 상태·검증 문서를 따른다.

확대 준정적 계산은 E03으로 구현·검증했고 E01은 실제 구조/실해상·확대 구조 모델과 선사별 승인 연계로 추적한다. 사용자 요청에 따라 이후 프런트는 브라우저 없이 코드로 검증한다.


## 2026-10-14 장비 계열과 공개 선사 자료

기본 DB 장비는 5종이다. 분석/휴리스틱/CP-SAT는 제원과 규칙이 함께 등록된 추가 코드를 후보에 포함한다. 폭 때문에 필요한 수평 회전도 수정했다. 신규 타입 생성 화면과 냉동/탱크 전용 모델은 미구현이다. 공개 선사 출처 3개와 Hapag FR 표 8개 열을 읽기 전용 검토 API에 연결했다. 수치 충돌 열은 차단하고 외삽·자동 승인·자동 제원 반영을 하지 않는다. 세부 근거와 범위는 [PUBLIC-CARRIER-REFERENCES.md](PUBLIC-CARRIER-REFERENCES.md)를 참조한다. 브라우저 검증은 실행하지 않는다.


## 2026-10-14 장비 등록과 반입 개구부

장비 등록 화면/API가 물리 제원과 DEFAULT 규칙 및 확인 근거 감사를 한 트랜잭션으로 생성한다. 플랫폼 관리자만 생성하며 코드 충돌/잘못된 비율/닫힌 면 초과 허용을 거부한다. 개구부 검토는 MASTER 조회 권한으로 선언된 유효 개구부의 DOOR/TOP/SIDE 직사각형 단면과 면당 여유를 검사하며 수평90도 후보를 비교한다. 내부 이동 경로/인양/선사 승인 및 저장 계획 자동 변경은 제외다. 기존 미완료 큰 항목을 E01 실제 증빙/승인, E04 확대 구조, S01 냉동·탱크 전용 운용으로 분리하고 M03/M04를 추가했다. 확장 기능 정의는 전체35·완료32·미완료3이며 과거31개 집계는 당시 범위다.


## 계획별 증빙 보관과 문서상 결정

E01의 소프트웨어 범위를 확장했다. 기존 oog_engineering_review의 EVIDENCE_FILE 기록으로 계획·회사에 연결된 원본 사본과 SHA-256, 대상 식별, 발행자, 문서번호, 발행/유효일, 외부 문서상 결정을 보존한다. PDF/PNG/JPEG 10MB 이하를 저장하며 원본 다운로드는 계획 소유/출력 권한과 실제 바이트 해시를 검사한다. 같은 범주·대상의 최신 기록으로 범주 존재 여부만 점검하고 만료/거절을 제외한다. 과거 자료는 API에서 수정/삭제하지 않는다. 기존 DB 테이블을 사용하여 V10/25개 테이블을 유지한다. 외부 문서 진위·모든 화물/장비별 증빙 완전성·실제 운송 승인과 자동 계획 변경은 제공하지 않는다. E01은 여전히 진행/검증 대기이며 전체35·완료32·미완료3을 유지한다.


## OOG 핵심 범위 정정과 연성 구조 계산

냉동·탱크 전용 운용은 사용자의 OOG 의도보다 넓게 확장한 항목이므로 S01을 핵심 기능과 집계에서 제외한다. 실험 코드와 계산 초안은 reference/experimental-special-equipment-20261014에 보존하고 실제 API는 REEFER/TANK 요청을 거부한다. 프로그램은 Dry/HC와 비교하는 OT/FR/Platform/Multi-FR/Breakbulk 계획에 집중한다. 따라서 현재 기능은 전체34·완료32·진행2·검증32통과/2대기다.

E04에 일정 EI 1차원 Euler-Bernoulli 보와 공면·간극0 압축 스프링의 연성 FEM을 추가했다. 최대 8지지/16하중의 접촉 집합을 검사하고 평형/접촉 잔차를 만족하는 해만 반환한다. 구간 Hermite 3차식의 내부 처짐 극값도 계산한다. 3D 장비 전체/비틀림/좌굴/피로/국부 접합부는 미구현이므로 E04 전체 완료로 처리하지 않는다. E01은 실제 파일 해시를 검증한 계획·증빙·수치/결정 기록 ZIP 출력까지 구현했으며 실제 자료 대조/진위/선사 승인 연계는 대기다.

정식 보 요소 근거: [TU Delft Euler-Bernoulli beam elements](https://interactivetextbooks.citg.tudelft.nl/computational-modelling/structural_linear/euler_bernouilli.html). 이 자료의 선형 보 요소를 사용했다는 사실은 실제 장비의 구조 인증을 뜻하지 않는다. 모든 결과는 PRE_PLAN이다.


## 원본 제원 참고와 실측 대조 확장

18개 원본 통합문서(17 XLSX·HTML 형식 XLS 1), XLSX 27개 시트의 비어 있지 않은 셀/수식, 도형 텍스트와 내장 이미지 1개를 조사했다. 도형/셀이 표시하는 항목이 실제 구조 도면이나 증빙이라는 뜻은 아니다. 일반 장비 제원 이미지의 비냉동 8종을 참고 후보로 전사하고 현재 DB와 차이만 비교한다. 실제 확인 근거·계획 비율은 자동 채우지 않는다. 세부 조사 기록은 engineering-source-inventory.json이다.

MEASUREMENT_CHECK는 같은 계획/회사에 속하는 최신·미만료 증빙 원본 해시를 검사하고, 사용자가 독립 입력한 포장 치수/중량 또는 계산 CoG/중량을 저장 사본과 대조한다. 잘못된 범주/대상·교체된 문서·변조 파일은 차단한다. 추정/불일치는 새 확인 사본 필요로 기록하며 저장 계획/계산을 변경하거나 실제 승인하지 않는다. 결과와 출처 바인딩은 검토 ZIP에 포함한다. E01의 실제 자료 진위/실물 대조/선사 연계와 E04의 실제 장비 전체 구조 검증은 계속 미완료로 유지한다.
