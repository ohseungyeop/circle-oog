# 확대 공학 모델의 원문 근거와 적용 경계

조사일은 2026-10-14(KST)이다. 공식 발행·배포 문서, 대학 강의 원문, 저널 발행사 공개 원문을 확인했다. 이 문서는 구현할 제한 모델의 연구 근거이며 코드 검증 통과·인증·선사 승인 선언이 아니다. 시험 자료가 없는 화물·장비·경로에 계수나 허용값을 자동 채우지 않는다.

## 3. 방향별 외력·두 지지점 반력: 구현을 위한 평형 유도

다음은 위 운송계수를 사용하되 자체적으로 자유물체도에서 유도한 준정적 내부 모델이다. 별도의 공인 계산식으로 인용하지 않는다. 좌표와 힘 방향을 입력·결과에 함께 저장해야 한다.

```
W_kN = mass_kg * 9.81 / 1000
Fh_kN = W_kN * ch
N_kN = W_kN * cz_min
Mtip_kNm = Fh_kN * d_m
Mstable_kNm = N_kN * b_m
margin_kNm = Mstable_kNm - Mtip_kNm
```

b는 실제 전도축에서 CoG까지 거리다. 외포장 폭/길이의 절반을 실제 지지 경계로 자동 사용하지 않는다. CoG가 지지 다각형 밖이거나 축이 확인되지 않으면 기하학적 유효성을 먼저 거부한다. 음의 여유는 한도 미충족, 0은 한계 상태로 표시한다. 고박 모멘트를 별도로 모델링하지 않았다면 0보다 큰 여유도 운송 승인과 다르다.

X방향 두 압축 지지점 xA<xB, 공통 지지면 높이 zS, +X 외력 Fx의 경우:

```
RB = [N*(xG-xA) + Fx*(zG-zS)] / (xB-xA)
RA = N-RB
```

좌표를 m로 통일하면 반력은 kN이다. -X는 Fx 부호를 바꾼다. 반력 음수는 압축 지지로 평형 불가능한 상태이며 0으로 잘라 재평형된 것처럼 표시하지 않는다. X축 두 점만 입력한 모델은 횡방향 모멘트 분배를 결정하지 못한다. 그 방향에는 실제 지지선/지지 다각형 또는 다점 지지 모델이 필요하다. 동적계수로 등가 정적 외력을 만든 모델이며 시간 적분·공진·충격 접촉 해석이 아니다.

## 4. 단순보 점하중: 응력·처짐

[MIT David Roylance, Beam Displacements](https://ocw.mit.edu/courses/3-91-mechanical-behavior-of-plastics-spring-2007/db3dd94238ceb7a9796bf5c7773afa0e_14_bdisp.pdf), 2000-11-30 원문을 확인했다. PDF 2쪽 식 (3)–(4)는 모멘트에서 두 번 적분, 3쪽 식 (7)은 중앙 점하중 처짐, 9–10쪽은 선형 중첩과 임의 위치 점하중을 설명한다. [MIT David M. Parks, Euler-Bernoulli Beams](https://www.ocw.mit.edu/courses/2-002-mechanics-and-materials-ii-spring-2004/bc25a56b5a91ad29ca5c7419616686f7_lec2.pdf#page=4), PDF 4–6쪽은 변형·변형률·응력과 단면력 관계의 원문이다.

구현 단위는 P=N, x/L/a/b=mm, E=N/mm²(MPa), I=mm⁴, 단면 최외단 거리 c=mm로 통일한다. 일정 EI, 양끝 단순지지, 아래 방향 점하중 P, a는 왼쪽 지점부터 하중까지 거리, b=L-a일 때 아래 방향 처짐의 크기는:

```
RA = P*b/L, RB = P*a/L
M(x) = RA*x - P*max(0,x-a)
sigma(x) = M(x)*c/I
v(x) = P*b*x*(L²-b²-x²)/(6*L*E*I)           [0 <= x <= a]
v(x) = P*a*(L-x)*(L²-a²-(L-x)²)/(6*L*E*I)   [a <= x <= L]
```

여러 점하중은 각 항을 선형 중첩한다. 중앙 한 하중의 검산은 `Mmax=P*L/4`, `vmax=P*L³/(48*E*I)`이다. 처짐 최대 위치는 항상 중앙이 아니므로 구간별 기울기 0과 하중 위치·지점·경계를 평가해야 한다. 유한 간격 샘플만 사용하면 최대값은 근사임을 표시한다.

이 모델은 가늘고 선형 탄성인 보의 작은 변형에 한정한다. 전단 변형·비틀림·국부좌굴·소성·용접/체결·비균질 또는 변단면·실제 FR deck 구조 모델은 별도다. 허용 응력·허용 처짐·E·I·단면 c는 실재 구조/재료 자료로 확인하며 장비 payload에서 역산하지 않는다. 물성값이 있어도 실제 장비가 이 단순보와 같은 경계조건을 갖는지는 별도로 확인해야 한다.

## 5. 다점 탄성 지지와 압축 접촉

공개 학술 원문은 Grzesikiewicz와 Zbiciak, *Mathematical Formulation of Soft-Contact Problems for Various Rheological Models of Damper*, Shock and Vibration, 2018, article 8675016, 9 pages, [DOI 10.1155/2018/8675016](https://doi.org/10.1155/2018/8675016)이다. [발행사 공개 HTML 원문](https://onlinelibrary.wiley.com/doi/10.1155/2018/8675016) §2, 식 (1d) 설명과 Figure 2에서 비접촉이면 반력 0, 접촉이면 비음수 반력인 일방 접촉 관계를 확인했다. §5의 시간 이력 사례도 접촉과 분리를 구분한다. 발행사 PDF 요청은 이 조사 도구에서 실패했으므로 확인하지 않은 PDF 쪽수는 부여하지 않는다.

이 논문은 점 질량·점탄성/소성 충돌 모델 연구이며 OOG 다중 받침 계산을 검증한 자료가 아니다. 프로그램의 선형 압축 스프링 모델은 아래와 같이 자체적으로 선언·유도한다. 지지 강성은 재료·받침·deck·접촉 조합에 대한 사용자의 검증 자료가 필요하다.

공통 수평 접촉면의 지지 i 좌표 xi,yi(mm), 강성 ki(N/mm), 강체의 하향 병진 w(mm), 작은 회전 계수 θx,θy(rad), 초기 간극 gi(mm)를 정의한다.

```
di = w + θx*yi - θy*xi - gi
Ri = ki*max(0,di)
sum(Ri) = N
sum(xi*Ri) = specified first moment about y
sum(yi*Ri) = specified first moment about x
```

회전·모멘트 부호는 좌표 정의에 맞춰 일관되게 사용한다. 고정된 접촉 집합에 대해서는 3자유도 선형 평형을 풀 수 있으나, 압축 전용이므로 전체 문제는 접촉 집합 선택을 포함한다. 활성점은 di≥0, 비활성점은 di≤0, Ri≥0, 평형 힘·모멘트 잔차, 독립 지지점 배치와 행렬 조건을 모두 검사해야 한다. 음수 반력 점을 한 번 제거한 뒤 재접촉을 검사하지 않는 절차는 일반적인 정확해 보장이 없다. 수렴 실패·특이 지지 배치·평형 불가능은 결과 불가로 남긴다. 검증되지 않은 강성을 전부 같은 값으로 채우거나 중량을 받침 수로 균등 나누지 않는다.

강체·작은 회전·압축 전용·평면 받침의 준정적 모델이다. 마찰 접촉력, 접촉면 압력 피크, deck/화물 자체 굽힘, 재료 비선형, 동적 충격·진동·감쇠와 지지 파괴 후 운동은 이 식에 포함되지 않는다. 이 모델과 앞의 탄성 보 모델은 서로 다른 이상화이며 두 결과를 자동 합성해 실제 구조 승인으로 만들지 않는다.

## 6. 입력·검증·승인 경계

경로별 운송 모드·해역·방향과 각 계수 출처, 질량·CoG·실제 지지 경계, 강성·접촉면·허용값·단면 물성·하중 근거를 기록한다. 공식 표의 조건과 사용자 선언값을 분리하고 불명확한 경로에는 추천값을 확정 적용하지 않는다. 확인되지 않은 값은 추정/입력 부족으로 남긴다.

구현 검산에는 중앙/비대칭 점하중의 알려진 해, 영 외력 정적 환원, 부호 반전 대칭, 임계 전도 등호, 음수 반력, 회전/이동 평형 잔차, 강성 스케일 변화, 비접촉 재진입과 특이 배치를 포함한다. 모델 시험·실제 장비/운송 검증을 수행하기 전에는 결과를 제한 모델 계산으로 제공한다. 전체 경로·실 장비 구조·고박 배치·선사와 담당 공학 검토가 완료되지 않은 CLP는 PRE_PLAN이다.

## 7. 논문을 참고한 접촉 마찰·수평력·yaw 동시 평형

Boyd와 Wegbreit의 *Fast Computation of Optimal Contact Forces*, IEEE Transactions on Robotics 23(6), 2007, DOI [10.1109/TRO.2007.910774](https://doi.org/10.1109/TRO.2007.910774)의 [저자 Stanford 공개 원문](https://web.stanford.edu/~boyd/papers/pdf/fast_opt_force.pdf#page=3)을 확인했다. PDF 2–3쪽(저널 1118–1119쪽)의 식 (1)–(2)는 접촉 마찰원뿔, 식 (4)는 힘 평형, 식 (5)–(6)은 모멘트를 포함한 wrench 평형이다. 논문의 해법은 SOCP 구조를 활용하는 내부점 방법이며 목적함수는 접촉력 최대 크기의 최소화다.

본 프로그램은 그 힘·모멘트·개별 마찰 한도를 동시에 만족시켜야 한다는 원리를 참고한다. 논문의 내부점 구현이나 쌍대 하한·불가능 증명·최적성 보증을 구현했다고 주장하지 않는다. 먼저 압축 스프링 모델로 얻은 정상력 Ri를 고정한 뒤 접촉면의 직교 접선축 X,Y에서 패드별 접선력 txi,tyi를 구한다. 접촉 평면의 좌표 원점은 CoG의 수평 투영점이다.

```
sqrt(txi²+tyi²) <= mu*Ri                     [kN]
sum(txi) + Fx_external = 0                    [kN]
sum(tyi) + Fy_external = 0                    [kN]
sum[(xi-xG)*tyi - (yi-yG)*txi] + Mz_external = 0  [kN*mm]
```

Ri=0인 패드는 접선력을 제공하지 않는다. 전체 마찰력 상한과 전체 회전 저항 상한을 각각 통과해도 동시 배분이 가능하다는 뜻은 아니다. 특히 모든 패드가 +X 외력을 저항하는 데 마찰 한도를 전부 쓰면 추가 yaw 저항에 쓸 여유가 없을 수 있다. 따라서 개별 힘 벡터를 포함하는 실제 배분 증거와 세 평형 잔차를 보존한다.

수치 방법은 Bauschke, Burachik, Herman, Kaya, *On Dykstra’s algorithm: finite convergence, stalling, and the method of alternating projections*, [저자 arXiv 원문 2001.06747v1](https://arxiv.org/html/2001.06747), §1 식 (4a)–(4b)의 보정항을 가진 교대 투영을 참고한다. 이 원문은 볼록 집합 교집합으로의 투영과 정체 현상을 다루며, 유한 반복 한도에 도달했다고 교집합이 비었다는 결론을 주지 않는다.

프로그램은 힘·yaw 평형의 affine 집합과 패드별 Coulomb 원판들의 곱 집합 사이를 Dykstra 방식으로 투영한다. 회전 행은 지지점 거리 척도로 나눠 힘 행과 수치를 맞추며, 반환 시 yaw 잔차는 kN·m로 변환한다. 계산된 배분의 모든 힘이 유한하고 각 원판 한도와 세 잔차 허용오차를 만족할 때만 `VERIFIED_PRIMAL_ALLOCATION`으로 표시한다. 반복 내 증거를 얻지 못하면 `NOT_PROVEN_WITHIN_ITERATION_LIMIT`이며 물리적 불가능 증명과 구분한다. 필요한 전체 상한을 넘은 경우의 거부도 별도 상태다.

0에서의 투영은 이론적으로 제곱 접선력 합이 작은 배분과 관련되지만, 현재 구현은 실제 가능 배분 확인 시 종료한다. `sumSquaredTangentialForcesKn2`는 반환 배분의 지표이며 최솟값 보증이 아니다. `optimalityCertified=false`를 유지한다. 수치 평형 증거는 강성·마찰계수·입력 힘의 실측 확인이나 전체 운송 적합성을 대신하지 않는다.

독립 검사에서는 영하중, 중심 수평력, 순수 yaw, 전체 회전 상한 초과, 수평력과 yaw의 동시 한계, 비접촉 패드, 좌표 원점 이동을 포함한다. 성공 결과마다 반환된 패드별 힘에서 원판 한도와 Fx/Fy/Mz 평형을 다시 계산하며 솔버의 표시값만 신뢰하지 않는다. 예를 들어 CoG 기준 x/y가 ±500 mm인 네 패드, 패드당 마찰 한도 1 kN에서 Fx=4 kN와 비영 yaw는 각 총량 상한을 개별 통과해도 동시 평형이 불가능하다.


## 8. 구현의 추가 수치 경계

패드 해는 전체 접촉 집합부터 검사해 일반적인 전 접촉 경우의 불필요한 조합 탐색을 줄인다. 실패하면 최대 12개 패드의 접촉 조합을 모두 조사하고 비접촉점의 비침투 조건도 확인한다. 힘과 좌표 1차 모멘트 잔차를 보존한다. 작은 회전 기울기 0.01과 보 처짐/경간 0.01은 이 프로그램의 보수적 적용성 차단값이며 공인 허용 기준을 대신하지 않는다.

보 그룹의 패드들은 선택 X/Y축에 평행한 동일 직선에 있어야 한다. 서로 다른 선의 패드를 한 보로 투영하는 입력은 거부한다. 스프링은 사용자가 선언한 독립 대각 강성이고 보와 패드의 상호 유연성을 연계한 유한요소 해석이 아니다. 격자 보, 비틀림·좌굴·연결부·국부 지압·피로와 결합 강성 행렬은 별도 검토 범위다. CTU의 진동 이동 방지 고박 요구도 마찰력 수치 충족으로 면제하지 않는다.

입력과 결과·원본 계획 및 독립 결정 이력은 기존 불변 공학 원장에 저장한다. 기존 1.0 모델은 보존하며 확대 2.0 모델을 별도 목록으로 표시한다. 승인 여부는 해당 모델의 선언된 값과 가정에 대한 내부 검토이고 실제 장비 또는 선사 인증이 아니다.
