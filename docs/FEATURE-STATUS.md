## 미완료 및 실무 적용 조건

- 로그인 이후 UI 직접 업무검증은 미실시다. L03 2D는 build만 확인하여 검증 대기다.
- 기능 완료는 명시한 내부 범위 기준이다. M01의 장비 편집, M02 다중 선사 Rule, L05 Multi-FR 대수/지지점, O02 전용 PDF, C03 JWT/회사/RBAC, Q01 견적/포장추정, E01 공학은 남아 있다.
- 자동 매핑은 사용자 확인이 필요하며 단위·중량 기준을 자동 확정하지 않는다.
- 선사 제원·지지점·하중·CoG·라싱·실무 승인과 최적해 보장은 개발 완료 수치에 포함하지 않는다.
