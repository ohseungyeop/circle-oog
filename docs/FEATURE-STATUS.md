## 미완료 및 실무 적용 조건

- OOG 핵심 범위 전체34·완료32·미완료2(E01/E04), 기능검증32·대기2. 냉동·탱크 전용 운용 S01은 OOG 핵심과 무관하게 넓힌 항목이어서 집계에서 제외했다. 과거35개와의 차이는 범위 정정이며 완료 수를 늘린 것이 아니다.
- 실제 화면 대표 업무를 검증했으며 모든 브라우저·입력 조합의 무오류 보장을 뜻하지 않는다. 고객 원본파일18개는 읽기만 수행했다.
- CP-SAT 최적성은 적층없는 1열 모델에서 OPTIMAL인 경우만 확인된다. FEASIBLE·시간초과·128개 초과·수동 선택은 결과에 표시한다. 비용 최적화와 3차원 적재는 제외된다.
- FMS 공통 인증/회사/권한7개와 감사1개를 OOG에 연결했다. 추가 조직·구독·메시지·개인환경·채번 등은 미이식이다.
- 확인되지 않은 단위·중량 의미·운임·지지점·계수를 임의로 확정하지 않는다. CLP는 PRE_PLAN, 견적은 PRE_QUOTE를 유지한다.
- 확대 모델은 준정적 강체·공면·선형 독립 패드 스프링과 일정 EI 단순 보다. 실제 최대 압축 계수·강성·유효 라싱 용량과 실제 장력·재료/단면 허용값은 자료 확인이 필수다. Dykstra 반환 배분의 평형/마찰 증거만 검증하며 최적성 인증을 주장하지 않는다.
- 장비 신규 등록 화면/API 구현. 같은 계열도 선사·모델·상태가 다르면 별도 코드와 근거로 관리한다. 문/상부/측면은 선언 개구부의 직사각형 단면 검사이며 자동 CLP 승인이나 내부 이동 경로 해석은 아니다.
