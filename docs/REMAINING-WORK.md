# 남은 OOG 개발과 외부 확인

2026-10-14 현재 핵심 기능 34개 중 완료 32개, 진행 2개다. 냉동·탱크 전용 운용은 OOG 의도보다 넓게 확장했던 항목으로 핵심 기능/집계에서 제외했다. 완료 개수를 늘린 것이 아니라 35개 정의에서 S01을 제거한 범위 정정이다.

## 구현 및 검증한 추가 기능

장비 타입·모델 등록, 반입 개구부 검사, 계획별 실측/선사 증빙 원본과 해시 보관, 원본·계획·수치 계산·내부 결정이 포함된 검토 ZIP, 일정 EI의 보와 압축 탄성 지지의 연성 모델을 구현했다. 구조 모델은 알려진 해, 지지 이탈, 평형과 구간 내부 처짐 극값을 검증한다. 냉동·탱크 실험 코드는 reference/experimental-special-equipment-20261014에 보존하며 실제 API는 해당 종류를 거부한다.

## E01 실제 자료 대조와 선사 승인 연계

공개 선사 지침, 수치 모델, 독립 내부 결정, 증빙 보관과 외부 검토 자료 출력까지 구현했다. 개별 장비 식별/명판/모델/상태와 실제 화물 중량·CoG·지지/결속 증빙은 실물과 대조해야 한다. 일반 공개 제원을 개별 실물의 확인 값으로 대신하지 않는다. 외부 문서상 수락은 사용자 기록이며 발행자 진위 인증이 아니다. 실제 승인 주체의 접점/데이터 계약과 진짜 승인 결과가 있어야 실제 선사 연계를 검증할 수 있다.

## E04 실제 장비의 확대 구조 검증

현재 일정 EI 1차원 Euler-Bernoulli 보와 2~8개 공면·초기 간극0 압축 스프링의 연성 모델까지 구현했다. 지지와 점하중 위치를 절점으로 만들며 3차 Hermite 구간의 내부 극값, 모멘트·전단·처짐·평균 면압과 평형 잔차를 검사한다. 특정 장비 전체의 3차원 하중 분담·비틀림·국부 접합부·좌굴·피로·동적 응답은 이 모델로 계산하지 않으며 미구현으로 유지한다. 실제 도면·단면·재료·접합·경계·하중 조합을 확보하여 해당 모델을 만들고 독립 결과와 비교해야 한다.

모든 CLP는 PRE_PLAN이며 위 두 항목이 실제 검증되었다고 표시하지 않는다. 프런트는 사용자 지시에 따라 브라우저 없이 코드로 검증한다.


## 원본 제원 참고와 실측 대조 확장

18개 원본 통합문서(17 XLSX·HTML 형식 XLS 1), XLSX 27개 시트의 비어 있지 않은 셀/수식, 도형 텍스트와 내장 이미지 1개를 조사했다. 도형/셀이 표시하는 항목이 실제 구조 도면이나 증빙이라는 뜻은 아니다. 일반 장비 제원 이미지의 비냉동 8종을 참고 후보로 전사하고 현재 DB와 차이만 비교한다. 실제 확인 근거·계획 비율은 자동 채우지 않는다. 세부 조사 기록은 engineering-source-inventory.json이다.

MEASUREMENT_CHECK는 같은 계획/회사에 속하는 최신·미만료 증빙 원본 해시를 검사하고, 사용자가 독립 입력한 포장 치수/중량 또는 계산 CoG/중량을 저장 사본과 대조한다. 잘못된 범주/대상·교체된 문서·변조 파일은 차단한다. 추정/불일치는 새 확인 사본 필요로 기록하며 저장 계획/계산을 변경하거나 실제 승인하지 않는다. 결과와 출처 바인딩은 검토 ZIP에 포함한다. E01의 실제 자료 진위/실물 대조/선사 연계와 E04의 실제 장비 전체 구조 검증은 계속 미완료로 유지한다.
